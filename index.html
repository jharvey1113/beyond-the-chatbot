The Pocket Expert

Saves: answering the same 20 questions over and over ParasSPEDAnyone

A custom AI skill that knows your world: your standards, your accommodation lists, your policies. One job, done well. Mine checks IEP goals against IDEA. Another gives paras a scaffolding strategy in seconds.

Heads up: the platforms are changing. ChatGPT is retiring Custom GPTs and replacing them with Plugins. Google is turning Gemini Gems into Skills. The lesson: don't build for one platform. Build a portable skill, meaning clear instructions plus your reference files, that you can paste into whichever AI your district uses this year and next.

The secret from Chapter 5 still applies: structured instructions beat paragraphs. It's like bowling with the bumpers up. This prompt interviews you and writes a skill that works on any platform.

The prompt

Paste into any AI
I want to build a reusable AI skill for my job in a K-12 school. It needs to be PORTABLE so I can use it in Gemini, ChatGPT, Copilot, or Claude, even as those platforms change.

Interview me ONE question at a time to figure out:
1. Who will use it (me, paras, teachers, office staff, etc.)
2. The ONE job it should do really well
3. What reference files I should attach (standards, policies, accommodation lists). No student names or student data.
4. The rules it must always follow (for example: "never do the student's work for them," "always say which document the answer came from," "if you don't know, say so")
5. Exactly what format every answer should come back in

When the interview is done, give me a finished "Skill Card" with these labeled parts:
- NAME: short, lowercase, with hyphens (for example: iep-goal-checker)
- WHEN TO USE: one or two sentences describing when this skill should be used
- INSTRUCTIONS: step-by-step rules in structured, labeled sections (not long paragraphs)
- OUTPUT FORMAT: the exact layout every answer should follow
- REFERENCE FILES: the list of documents I should attach
- TEST QUESTIONS: 3 questions I can use to check that it works

Then tell me exactly where to paste it in the AI tool I use at work.

Where to put your Skill Card

  • Gemini: create a Skill, then call it with / in the chat box.
  • ChatGPT: create a Plugin. Your instructions become its skill and your documents become its reference files.
  • Copilot: create an agent in Copilot Studio and add your documents as knowledge.
  • Claude: add it as a Skill, or as Project instructions with your files.

Then run the 3 test questions and fix whatever it gets wrong. Save your Skill Card in a Google Doc. If the platform changes again, you can paste it somewhere new in five minutes.

The Guardrails (Chapter 8)

  
If it's not secure, don't build it.

  
    
    
  1. Fake data first. Test every build with made-up students and your own email.
    2. 
    
  2. Describe the data. Never paste it. Tell the AI "Column A has student names." Don't paste the names into the chat.
    3. 
    
  3. Keep it in your house. Scripts run inside your district Google or Microsoft account, so the data stays where it already lives.
    4. 
    
  4. Always build a fail-safe. "If it's not found, leave it for me." A tool that quietly skips a parent is worse than no tool.
    5. 
    
  5. Read-only first. Never let a first run delete or move anything. Report first, act second.
    6. 
    
  6. Know your policy. Check your district's data privacy and FERPA rules before going live with real students.
