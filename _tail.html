The Guardrails (Chapter 8)

If it's not secure, don't build it.

  1. Fake data first. Test every build with made-up students and your own email.
  2. Describe the data. Never paste it. Tell the AI "Column A has student names." Don't paste the names into the chat.
  3. Keep it in your house. Scripts run inside your district Google or Microsoft account, so the data stays where it already lives.
  4. Always build a fail-safe. "If it's not found, leave it for me." A tool that quietly skips a parent is worse than no tool.
  5. Read-only first. Never let a first run delete or move anything. Report first, act second.
  6. Know your policy. Check your district's data privacy and FERPA rules before going live with real students.
